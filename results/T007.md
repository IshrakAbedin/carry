## Bugs found and fixed

- **B1 — generated lib target had no dependency includes/links** (fixed → **D10**).
  Symptom: `carry build` of the fmtapp failed at link:
  `undefined reference to 'fmt::v12::vformat[abi:cxx11](…)'` from
  `libfmtapp_lib.a` — `#include <fmt/format.h>` in `src/lib.cpp` resolved to the
  **system** fmt v12 headers (`/usr/include/fmt`, present on this machine) while
  the link line used Conan's `libfmtd.a` (v10); the inline-namespace versions
  mismatch. Fix in `generate.rs`: the `{name}_lib` target now gets
  `target_link_libraries({name}_lib PUBLIC <pkg>::<pkg> …)` when deps exist.
  PUBLIC so consumers of the generated library get the dep's includes/links
  transitively (the exe/test keep their explicit lists — needed for bin-only
  projects). Goldens `GOLDEN_CMAKE_BOTH_DEPS` / `GOLDEN_CMAKE_LIB_DEP` updated,
  new golden `GOLDEN_CMAKE_BIN_WITH_DEP` + test. DESIGN.md §5 example line added.
- **B2 — `carry add fmt@` silently degraded to bare `fmt`** (fixed → D11).
  `parse_dep_spec` now rejects an `@` with an empty version:
  `error: missing version after '@' in "fmt@"` + `help:` hint, exit 1, manifest
  untouched. Unit test in `parse_dep_spec_forms` + e2e assertion in
  `add_remove_round_trip`.
- **B3 — bare `pkg` mapped to `pkg/*`, which Conan 2 cannot resolve** (fixed →
  D11). `carry add fmt` (no version) wrote `fmt/*` into conanfile.txt, and
  `conan install` failed: `ERROR: Package 'fmt/*' not resolved: Unable to find
  'fmt/*' in remotes` — **even with `fmt/10.2.1` in the local cache**. The `*`
  is looked up literally in a require (cache, then remote 404); only bracketed
  ranges resolve (`fmt/[>=10]` and `fmt/[>=0]` both resolved to the cached
  10.2.1). Fix: `conan_ref` maps an empty version to `pkg/[>=0]` ("any version"
  = highest available, cache preferred). DESIGN.md §4 mapping line corrected.
  Verified end to end in a scratch bin project: `carry add fmt` → conanfile
  `fmt/[>=0]` → build green, `fmt::print` linked against Conan's fmt.
  `conan_ref_branches` unit test updated.
