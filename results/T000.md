## Key decisions

All in DESIGN.md `## Decisions` (D1–D8). The load-bearing ones for later tasks:
- **D1** Rust implementation; deps kept minimal (clap, anyhow → +serde/toml/toml_edit in T002).
- **D2/D5** Conan 2, `conanfile.txt` generated; configure via `-DCMAKE_TOOLCHAIN_FILE=build/conan_toolchain.cmake`.
- **D3** `CARRY.toml` is single source of truth; `conanfile.txt` + `CMakeLists.txt` regenerated
  write-if-changed on every build.
- **D4** build dir `build/`, Debug default, `--release` opt-in.
- **D6** gcc/g++ pinned via CMAKE_C(CXX)_COMPILER.
- **D8** network-dependent E2E tests are `#[ignore]`d; T007 answers the network question.
