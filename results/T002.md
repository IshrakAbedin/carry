# T002 — Manifest (CARRY.toml) + `carry new` / `carry init` (DONE 2026-09-21)

## What was done

- **Deps added** (`cargo add`): `serde 1.0.229` (derive), `toml 1.1.6`, `toml_edit 0.25.15`.
- **`src/manifest.rs`** — serde schema per DESIGN §4:
  - `Manifest { package: Package, build: Build, dependencies: BTreeMap<String,String> }`,
    all fields `#[serde(default)]`; defaults: version `0.1.0`, type `bin`,
    cpp_std `c++23`, c_std `c11`, empty deps. `type` is the field `kind`
    (renamed via serde to avoid the `type` keyword).
  - `Manifest::load(path)` — read + parse + validate.
  - `Manifest::save(path)` — via `toml_edit`: existing file is parsed and updated
    in place (comments/formatting survive); missing file is written from
    `toml::to_string_pretty` re-parsed into a `DocumentMut`. Stale dependency
    keys are removed on save.
  - `validate()` — name `[a-z0-9_][a-z0-9_-]*`, type ∈ {bin, lib, both},
    non-empty version; failures carry `help:` hints (DESIGN §8).
  - `conan_ref(pkg, version)` — plain → `pkg/ver`; `>` `<` `=` `^` `~` prefix →
    `pkg/[range]`; empty → `pkg/*` (DESIGN §4). `#[allow(dead_code)]` until T003.
- **`src/template.rs`** — scaffold:
  - `&'static str` consts (GITIGNORE, CONANFILE_PLACEHOLDER, CMAKELISTS_PLACEHOLDER,
    MAIN_CPP_BIN, MAIN_CPP_BOTH, LIB_HPP, LIB_CPP, TEST_MAIN_CPP) with
    `{name}`/`{ident}` substitution via `str::replace` (no `format!` on user input).
  - `cpp_ident(name)` — dashes → underscores, so names like `good-name` yield a
    valid C++ namespace; file paths keep the raw name.
  - `cmd_new(name, lib)` — validates name; refuses to create over an existing
    non-empty dir without CARRY.toml; `--lib` ⇒ type `both`.
  - `cmd_init()` — cwd; name = dir name (validated); type always `bin`; errors if
    CARRY.toml already exists.
  - Placeholder `conanfile.txt` (`[generators]` only) + minimal valid
    `CMakeLists.txt` stub with the "replaced by real render in T003" comment —
    T003 territory, kept minimal per task notes.
- **`src/main.rs`** — dispatch seam: `main()` now calls `run(cli) ->
  anyhow::Result<()>` (the old stub used a `-> !` closure; real commands need a
  Result). `New`/`Init` call the real functions; the other six arms unchanged
  ("not implemented yet"). `#[allow(dead_code)]` removed from the `mod
  manifest;`/`mod template;` lines.
- **Tests** (`#[cfg(test)]` in manifest.rs, 9 total): full parse, minimal parse
  (defaults), scaffold-shape parse (empty `[dependencies]` table), save→load
  round-trip, save preserves comments, save removes stale deps, name-rule
  table, validate rejections (all carry `help:`), all `conan_ref` branches.
- File-based tests write scratch under `target/tmp/` (gitignored), cleaned per run.

  tree already contained the T002 implementation (uncommitted, no results file,

  T002 scope exactly, and was verified rather than redone. One gap was found and

  (keeping the key's leading-comment decoration and the value's trailing
  decoration) — this is what makes `save` comment-preserving and is what T006's
  format-preserving `add`/`remove` will build on.
- `--lib` on `new` ⇒ type `both` (task note); `init` has no `--lib` flag in the
  DESIGN §2 command table ⇒ always `bin`.
- `cmd_init` name = `cwd.file_name()`; empty/non-UTF-8 dir names fail
  `validate_name` with the standard rule hint.
