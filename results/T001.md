## Key decisions

- **Corrections to the task notes** (task file `tasks/T001-cli-scaffold.md` says the same):
  - `#[command(trailing_var_arg = true, allow_hyphen_values = true)]` on the `run` field
    does not compile on clap 4.6.7 ("expected `arg` attribute instead of `command`");
    the correct form is `#[arg(trailing_var_arg = true, allow_hyphen_values = true)]`.
  - A bare `#[allow(dead_code)]` in an otherwise empty module file is a syntax error
    ("expected item after attributes"). The allows therefore sit on the `mod`
    declarations in `main.rs` (one per module) — still "module level", removed as each
    module becomes used.
- Errors go to **stderr** (`eprintln!`); exit code 1 for carry errors, matching DESIGN §8.
- `--verbose` is a global clap flag (parses before *or* after the subcommand); it carries
  `#[allow(dead_code)]` until T004 wires it to command printing.
