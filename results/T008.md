## Key decisions

- None new for DESIGN.md — T008 is docs/help/verification only, per its scope.
- One **benign** observation recorded (not an issue): on *re*-configure, CMake prints
  `CMake Warning (unused-cli): Manually-specified variables were not used by the project:
  CMAKE_TOOLCHAIN_FILE` — the toolchain path is already cached from the first configure, so
  the flag is redundant but harmless. Reconfiguring every build is intentional (keeps conan
  updates in sync; DESIGN §6 step 4); suppressing it would require stateful configure logic
  — out of MVP scope. Joins the known gnu20-vs-c++23 configure warning (results/T004.md).
