# T003 — Generator: manifest → conanfile.txt + CMakeLists.txt

Status: pending

## Goal

Replace the T002 placeholders with the real generator: render `conanfile.txt` and
`CMakeLists.txt` from the `Manifest` (DESIGN.md §5), write-if-changed semantics, and make
`carry build`/`run`/`test` call it as their first step (the build steps themselves stay
stubbed until T004).

## Context

- Read `DESIGN.md` §5 (exact generated-file formats) and `results/T002.md` (manifest API,
  `conan_ref` helper).
- Work in `src/generate.rs`.

## Requirements

- `fn render_conanfile(m: &Manifest) -> String` — per DESIGN §5: `[requires]` section (one
  `conan_ref` line per dependency, sorted by package name for determinism), then
  `[generators]` with `CMakeDeps` and `CMakeToolchain`. No `[requires]` section header when
  there are zero deps (Conan tolerates it either way, but keep the file minimal — document
  the choice in results).
- `fn render_cmake(m: &Manifest) -> String` — per DESIGN §5 template exactly:
  - `cmake_minimum_required(VERSION 3.21)`, `project(<name> VERSION <version> LANGUAGES C CXX)`,
    std settings, `CMAKE_RUNTIME_OUTPUT_DIRECTORY ${CMAKE_BINARY_DIR}/bin`.
  - One `find_package(<pkg> REQUIRED)` per dep.
  - Targets per `type`: `lib` → `add_library(<name>_lib STATIC src/lib.cpp)` + PUBLIC include
    dir; `bin` → `add_executable(<name> src/main.cpp)`, linking `<name>_lib` (if present)
    then each `<pkg>::<pkg>`, PRIVATE include dir. `both` → both, executable links lib.
  - `enable_testing()`, `test_<name>` executable from `tests/test_main.cpp` linking the
    primary target + deps, `add_test(NAME <name>_tests COMMAND test_<name>)`.
  - First line of the file: `# Generated by carry 0.1.0 from CARRY.toml — do not edit.`
- `fn regenerate(m: &Manifest, root: &Path) -> anyhow::Result<(bool, bool)>` — renders both,
  compares with on-disk content (read if exists), writes only when different, returns
  `(conanfile_changed, cmake_changed)`.
- Wire-in: `main.rs` — `build`/`run`/`test` first locate the project root (walk up from cwd
  for `CARRY.toml`; implement `project::find_project_root()` in `src/project.rs`), load the
  manifest, call `regenerate`, then still return the existing "not implemented" build error.
  `new`/`init` now write the real rendered files instead of placeholders (delete the
  placeholder code from template.rs).
- Unit tests in `generate.rs`: golden-string assertions for (a) bin-only, no deps; (b) both,
  two deps (one plain version, one range); (c) idempotence — `regenerate` twice, second call
  changes nothing (use `tempfile` crate → `cargo add tempfile --dev` is allowed for tests).
